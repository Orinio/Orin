# Orin

Orin is an AI-powered career intelligence platform that turns scattered student work — GitHub repos, certificates, competitions, projects — into verified, portable **Proof Cards** with confidence scores. Built with Next.js 16, Express.js, Supabase (PostgreSQL + RLS), and NVIDIA NIM (Qwen/GPT-OSS models), it provides AI agents for career coaching, portfolio verification, skill analysis, opportunity matching, and learning path generation — all grounded in real evidence with traceable source attribution.
